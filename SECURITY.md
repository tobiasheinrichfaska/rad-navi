# Security Policy

rad-navi is a client-side React library (no server, no network access, no stored secrets).

## Reporting a vulnerability

Please do **not** open a public issue for a security problem. Use GitHub's private vulnerability
reporting (Security tab → "Report a vulnerability") on this repository.

You can expect an answer within a few days. Fixes are released as a new version; the package is not
published to npm, apps take it by Git tag.

## Scope

Supported: the latest version on `main`.
